# Research scripts

These scripts produced every number of the KabOCR paper (test-set construction, training lists, leakage audit, evaluation, baselines, robustness sweep, learning curve, figures). They are published for transparency and reproduction. They were written for the original machine, so **adapt the absolute paths at the top of each script** to your copy. The test sets are rebuilt from the public `taqbaylit/*` collections on Hugging Face (`build_set.py`); no copyrighted page is redistributed here.
